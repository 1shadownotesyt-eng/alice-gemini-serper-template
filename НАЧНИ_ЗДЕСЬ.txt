НАЧНИ ЗДЕСЬ — навык Яндекс Алисы с Gemini

ВАЖНО: если этот проект опубликован на GitHub, проще нажать Fork и подключить копию к Vercel. ZIP скачивать необязательно.

Если вы скачали ZIP:
1. Распакуйте архив двойным кликом.
2. На GitHub нажмите + → New repository и создайте репозиторий.
3. В пустом репозитории нажмите Add file → Upload files.
4. Перетащите содержимое этой папки. Обязательно сохраните папку api и файл api/index.js внутри неё.
5. Нажмите Commit changes.
6. Войдите на vercel.com, нажмите Add New… → Project и импортируйте свой репозиторий.
7. После первого Deploy добавьте ключи в Project → Settings → Environment Variables:
   GEMINI_API_KEY — ключ Google AI Studio.
   SERPER_API_KEY — ключ Serper.
   Для обеих переменных выберите Production.
8. После сохранения переменных сделайте Redeploy и дождитесь Ready.
9. Скопируйте домен Vercel, добавьте /api и вставьте полный адрес в Webhook URL своего навыка в Яндекс Диалогах.
10. Проверьте навык через тестер Яндекс Диалогов.

Ключи храните только в Vercel. Никогда не добавляйте их в GitHub или код.
Подробности — в README.md.
